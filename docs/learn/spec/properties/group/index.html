group

Use the group Property field to group a Module's related properties together. When a Module is displayed to a user, grouped properties are called out into their own area which contains each Property of the group. The group value is purely for display purposes and has no impact on any other aspect of using a Property.

group field​

The group Property field can contain any string you want, but it is desirable to keep this short (less than 16 characters or so) and minmize any non-alphanumeric characters.

group ordering​

When a Module has groups the are renderer in the order they first occur within the Properties Declaration. For example, if we had the below properties with groups defined the order of the groups would be Visualization followed by Options.

properties.yaml
value:
  datatype: text
show_value:
  datatype: boolean
  group: Visualization
min:
  datatype: number
  group: Options
max:
  datatype: number
  group: Options
